# Proofs Overview

This document summarises the current formal proof tree for LaTeX
Perfectionist. All proofs compile with zero admits and zero axioms.

## Totals

192 Coq files, 1,591 theorems/lemmas (declarations), 0 admits, 0 axioms.
All counts are generated into `governance/project_facts.yaml` by
`scripts/tools/generate_project_facts.py` and gated by `check_repo_facts.py`.

- ⚠ 803 of the 1,591 theorems are the generated per-rule "soundness" theorems in
  `proofs/generated/`. They share one proof body (`Proof. qed_text_sound. Qed.`)
  and each restates its checker's own definition; 57 of those checkers are the
  constant `false`, and nothing ties a checker to the shipped OCaml rule
  (OPEN-067). The other 788 are everything else. That is a count of
  declarations, not a measure of strength.

Breakdown (non-archive `.v` files, recursive):

- **Core proofs** (65 files, top level of `proofs/`): lexer, parser, expansion, semantic state,
  DAG, language contract, execution classes, partial-parse / damage /
  repair / stable IDs, project graph, hybrid invalidation, build-log
  conditional soundness.
- **Generated per-rule proofs** (114 files): VPD-family "soundness"
  generated by `scripts/infra/proof_farm/gen_coq_proofs.py` (see the ⚠ above).
- **ML proof** (1 file): `proofs/ML/SpanExtractorSound.v` — v2
  ByteClassifier precision/recall bounds.
- **Strict kernel** (12 files, `proofs/Strict/`): the L_S0 decider
  (`strict_decider_exact`, `decide_total`). Its bridge theorem
  `strict_ready_iff_pdflatex` holds under the premise `Faithful`, which is
  FALSE of the pinned pdfTeX (OPEN-124). The kernel is wired into no verdict.

## CI gate

`.github/workflows/proof.yml` builds the proof tree with `dune build`,
then greps for `Admitted.` / `admit.` / `Axiom` / `Parameter`. Exit 1
on any match. Runs on every push and PR; cannot be bypassed.

Run locally:

```bash
OPAMSWITCH=l0-testing opam exec -- dune build @coq
```
