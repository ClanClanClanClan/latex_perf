lived in three places a future reader could not reach: an agent's private memory,
ephemeral `/tmp` workflow outputs, and PR descriptions. The repo itself carried a
ROADMAP whose banner, false-READY count, over-rejection claim and
version-of-record were each factually false while `check_roadmap_facts.py`
printed `Roadmap facts check passed`. Measured on 2026-08-22, **no in-repo prose
carried the real-paper measurement at all**, and the strings `declared_texlive`,
`rescue-alone` and the `corpora/unicode` finding appeared in **zero** files.

**The rules that keep it true.**

1. Numbers in the generated block below come from the artefact that owns them.
   `check_project_state.py` regenerates and diffs. **Never hand-edit that block.**
2. Every open item has a stable `OPEN-nnn` id. Cite it in the PR that closes it.
   Ids are never reused.
3. Every claim carries provenance: a file:line, a command, or `UNVERIFIED`.
4. When a belief turns out to be wrong, it goes in §4 — the corrections log.
   That section is the point of this document, not an appendix to it.

## 5. Process invariants

Earned, each at a cost. Violating one is how the entries in §4 happened.

1. **Grade every corpus against the oracle, once, when you add it.** OPEN-001 exists because a corpus was added to test lint firing and never compiled.
2. **A verdict flip is not a win until pdflatex agrees.** (C-5)
3. **Verify a gate in BOTH directions** — clean pass *and* injected failure, naming the expected signal.
4. **Never trust a background run without a completion sentinel.** (C-9)
5. **Never set a latency threshold on this machine.** Load has been observed at 158–230. Interleaved A/B at load ≤ 8 only, and CI and this laptop compile different C tokenizers.
6. **Quote (c), or quote nothing.** (a) and (b) grade toy corpora.
7. **Edit `.github/required-status-checks.json`, never the branch-protection API** — `branch-protection.yml` PUTs the file on every push to main.
8. **Verify PR state via `statusCheckRollup`**, never by reading the check list.
9. **Order a release: CHANGELOG + ROADMAP prose first, `release.sh` second.**
10. **A gate nobody has seen fail is not a gate — and this is now MACHINERY, not a rule to remember.** `check_gate_selftests.py` (required, spec-drift + build) applies known-bad mutations to backup-restored inputs and asserts each covered gate fails WITH its expected message; the registry pins its own size, every anchor must match exactly once, and every `check_*.py` wired into spec-drift must be covered or carry a written exemption. Invariant 3 above, enforced mechanically. (OPEN-036)
11. **A published number must be recomputable from the artefact that carries it.** `results.json`'s `APPLIED TO k/n` protocol clause is recomputed from per-row `pdflatex_passes` on every `check_project_state` run (C-28); the differential's denominator is derived by the SAME enumeration rule the differential uses, pinned by an assertion (C-29). When you publish a claim, publish its derivation next to it and gate the two together.
12. **The oracle is the NEWEST STABLE TeX Live, rolled forward annually as a gated event — never via continuous `tlmgr` tracking.** Owner decision, 2026-08-25, with the TL2024 control on the table. Rationale: user engines are heterogeneous, so no single oracle is "correct"; you pick the one whose errors are least harmful. A false-READY under the newest engine bites a current-install author on their own machine (the cardinal bug, delivered personally); an over-rejection under the newest engine is soft, because the message can be version-conditioned ("fails under TL≥2026; compiles under earlier; fix: load amsthm after thmtools"). Fresh installs only move forward, so the newest-engine population grows monotonically. Version-sensitivity is DIAGNOSTIC METADATA, not an excuse: the TL2024 differential enriches messages, it does not move the pin backwards. The annual roll re-grades all corpora (STRICT_GRADE re-record) — which also catches version-sensitive classes healing as the ecosystem patches (the `\c@` class is likely transient). The l3backend incident is why the roll is never `tlmgr update`.
